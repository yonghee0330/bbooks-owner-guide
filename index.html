링크 쓰는 법

  1. 받으신 링크를 열어요. 휴대폰·컴퓨터 어디서나 열려요. 로그인은 필요 없어요. 위쪽에 "Google Apps Script 사용자가 만들었습니다"라는 안내가 보이는데, 비북스가 만든 페이지라는 표시이니 그대로 쓰시면 됩니다.
  2. 휴대폰 홈 화면에 추가해 두면 편해요.
    아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가
    안드로이드(크롬): 오른쪽 위 ⋮ → 홈 화면에 추가
  3. 링크는 점주님 전용이에요. 링크를 아는 사람은 누구나 내 서가 현황을 볼 수 있으니 다른 분께 공유하지 말아 주세요. 잃어버렸거나 공유된 것 같으면 비북스에 말씀해 주세요. 새 링크를 드리고 예전 링크는 막아 드려요.

링크가 안 열릴 때 — 카카오톡이나 다른 앱 안에서 링크를 누르면 "이동 중" 화면에서 멈출 때가 있어요. 링크 주소를 길게 눌러 복사한 뒤, 사파리나 크롬 주소창에 붙여 넣어 열어 주세요. 주소 끝의 ?k=… 부분까지 모두 있어야 열려요.

입고 요청하는 법

여러 권을 한 번에 신청할 수 있어요. 비북스가 확인한 뒤 입고를 도와드리고, 처리 상태는 같은 탭 아래 "보낸 요청"에서 볼 수 있어요.

  1. 책 찾기에 제목, 저자 또는 ISBN을 적고 검색해요. 찾은 책의 담기를 누르면 정가·저자·출판사가 자동으로 채워져요. 같은 책을 한 번 더 누르면 수량이 늘어요.
  2. 검색에 없는 책이나 굿즈는 직접 입력 추가로 제목과 가격을 적어요.
  3. 신청 목록에서 책마다 구분(새책·중고·굿즈)과 입고 방식(직접 입고·비북스 도매주문), 수량을 골라요. 중고·굿즈는 판매 희망가를 적어 주세요. 새책은 정가로 판매해요.
  4. 도매주문이 있으면 예상 입고가 합계가 보이고, 송금 또는 적립금 사용 중 결제 방식을 골라요. 송금을 고르면 비북스 계좌가 함께 보여요.
  5. 남길 말이 있으면 메모에 적고 입고 요청 보내기를 눌러요.

보낸 요청의 상태는 대기 → 승인 또는 입고완료로 바뀌어요.

정산 안내 메일 — 이메일 주소를 알려 주시면 매달 정산 금액과 적립·송금 내역을 메일로도 보내 드려요.

숫자가 제 기억과 달라요.

옮기면서 이름이 다르게 적힌 판매나 빠진 입고 기록이 있을 수 있어요. 어떤 상품이 몇 개인지 알려 주시면 비북스가 확인해 바로 맞춰 드려요.

오늘 팔린 책이 아직 안 보여요.

매장 판매는 보통 일주일 안에 반영돼요. 반영된 뒤에도 안 보이면 알려 주세요.

재고 수량이 실제 서가와 달라요.

상품 이름과 실제 수량을 알려 주세요. 회수하거나 분실된 상품도 함께 말씀해 주시면 정리해 드려요.

비북스에 알려 주세요. 새 링크를 드리고 예전 링크는 막아 드려요.
